Architecture Notes

  • Bitcask Engine: Active Write-Ahead Log (WAL) for append-only sequential writes + in-memory hash index mapping keys to segment file offsets.
  • O(1) Reads: Single disk seek directly to byte coordinates without scanning files.
  • Crash Safety: 22-byte binary framing with CRC-32 checksum per record. Partial/torn writes auto-truncated on boot.
  • Group Commit: Coalesces concurrent fsync requests into micro-batches for high durable write throughput.
  • Online Compaction: Dead space reclaimed into consolidated segments with companion .hint files for millisecond cold boots.
  • Zero Dependencies: Implemented purely on Java 21 standard library and Virtual Threads.
